# 로그인 서버 올리는 방법

게임의 로그인은 진행 기록을 **서버**에 보관해요. 서버를 인터넷에 한 번 올려 두면, 폰과 컴퓨터 어디서든 같은 아이디로 로그인해서 이어 할 수 있어요.
서버 코드는 이 저장소의 `app.py`이고, Render라는 서비스에 무료로 올릴 수 있어요.

> 서버를 올리기 전에도 게임은 그대로 할 수 있어요. 로그인만 안 될 뿐, 기록은 지금처럼 기기 안에 저장돼요.

---

## 1단계 · 계정이 사라지지 않게 할 저장소 만들기 (무료, 5분)

Render 무료 서버는 **다시 켜질 때마다 서버 안의 파일이 지워져요**. 15분 동안 아무도 안 쓰면 잠들었다가 다시 켜지기 때문에, 파일에 저장하면 계정이 금방 사라져요.
그래서 계정과 기록은 무료 데이터베이스(Neon)에 따로 보관해요.

1. https://neon.tech 에 들어가서 가입해요 (GitHub나 Google 계정으로 가입할 수 있어요).
2. 새 프로젝트를 만들어요. 이름은 아무거나(예: `beatblade`), 지역은 가까운 곳(예: Singapore)을 고르면 돼요.
3. 프로젝트 화면의 **Connection string**을 복사해요. `postgresql://`로 시작하는 긴 주소예요.
   이 주소는 비밀번호가 들어 있으니 다른 사람에게 보여 주지 마세요.

## 2단계 · Render에 서버 올리기

1. https://render.com 에 들어가서 **GitHub 계정으로 가입**해요.
2. 오른쪽 위 **New +** → **Blueprint**를 눌러요.
3. 저장소 목록에서 `apsule-quest-leaderboard`를 골라요. (안 보이면 GitHub 권한을 허락해 주세요.)
4. Render가 저장소의 `render.yaml`을 읽어서 설정을 채워 줘요.
   `DATABASE_URL` 칸이 나오면 1단계에서 복사한 주소를 붙여 넣어요.
5. **Apply**(또는 Deploy)를 누르고 몇 분 기다려요.
6. 다 되면 서버 주소가 보여요. 예: `https://capsule-quest-leaderboard.onrender.com`
   주소 뒤에 `/health`를 붙여 열었을 때 `"ok": true`가 보이면 성공이에요.

## 3단계 · 게임과 연결하기

- 게임은 처음부터 `https://capsule-quest-leaderboard.onrender.com`에 연결하게 되어 있어요.
- Render가 준 주소가 이것과 **다르면**, 게임의 「👤 로그인」 창 아래 **서버 주소**를 눌러 새 주소를 넣고 **바꾸기**를 누르세요.
  (Claude에게 주소를 알려 주면 게임 파일에 기본 주소로 넣어 드릴게요. 그러면 기기마다 바꿀 필요가 없어요.)

---

## 알아 두면 좋은 것

- **첫 로그인이 느릴 수 있어요.** 무료 서버는 한동안 안 쓰면 잠들어서, 깨어나는 데 최대 1분쯤 걸려요. 한번 깨면 빨라요.
- **비밀번호는 서버에 그대로 저장되지 않아요.** 되돌릴 수 없는 암호 형태(해시)로 바꿔서 저장해요.
  대신 비밀번호를 잊으면 **찾을 수 없어요**.
- **잘못된 비밀번호를 여러 번 넣으면** 10분 동안 그 아이디로 로그인할 수 없어요. 아무나 비밀번호를 계속 맞혀 보는 것을 막기 위해서예요.
- **게임을 켜면 로그인부터 해요(v77).** 로그인 창은 닫을 수 없어요. 서버에 연결이 안 될 때만 「오프라인으로 하기」가 나와요(그때 기록은 그 기기에만 남고, 다음에 켜면 다시 로그인 창이 나와요).
- **Google로 처음 들어오면 이름부터 정해요(v77).** 처음에는 서버가 `G_…` 임시 이름을 붙이고, 게임이 「이름 정하기」 창을 띄워요(한글·영문·숫자·_ 2~10자, 다른 사람과 겹치면 안 됨, 한 번 정하면 못 바꿈). 정한 이름이 랭킹과 게임 속 이름으로 나와요. 이미 `G_…`로 랭킹에 올라간 점수도 그 이름으로 바뀌어요. 아이디·비밀번호 계정은 아이디가 곧 이름이에요. 서버: `POST /api/account/name`, `/api/me`의 `need_name`.
- **인터넷이 끊겨도 게임은 돼요.** 기록은 기기에 먼저 저장되고, 다시 연결되면 서버에 올라가요.
- **두 기기에서 따로 진행했다면** 게임이 메뉴 화면에서 「서버 기록 / 이 기기 기록」 중 하나를 고르게 해요. 고르지 않은 쪽은 사라져요.
- 서버에 올라가는 것은 진행 기록(깬 보스, 코인, 상점 물건, 이야기 진행 등)이에요. 「내 이미지 바꾸기」로 넣은 그림과 싱크(박자 맞춤) 값은 기기마다 따로예요.
- 1단계를 건너뛰고 `DATABASE_URL`을 비워 두어도 서버는 돌아가요. 하지만 그때는 서버가 다시 켜질 때 계정이 지워질 수 있어요. 잠깐 시험해 볼 때만 그렇게 하세요.

# 결제(토스페이먼츠) 켜는 방법

게임 상점의 「구매하기」를 누르면 새 창에 **토스페이먼츠 결제창**이 떠요(카드 · 토스페이 · 카카오페이 · 네이버페이 · 계좌이체 · 휴대폰). 결제가 끝나면 서버가 토스에 "승인"을 받고, 그때 상품이 계정 보관함에 들어가요. 게임은 그걸 알아채고 바로 장착해요.

## 무료 출시 모드 (판매 끄기)

- Render → 서버 → **Environment**에 `SHOP_MODE` = `free` 를 넣고 저장하면, **웹·앱 모두에서 「✦ 스킨 · 무기 · 연출」 상점 탭이 사라지고** 서버도 주문을 받지 않아요.
- 다시 팔고 싶으면 `SHOP_MODE` 값을 지우면 돼요. 게임 파일은 다시 만들 필요 없어요.
- 이미 산 상품(보관함)은 무료 모드에서도 그대로 장착돼요.

## 현질템 직접 시험해 보기 (테스터 계정)

1. Render → 서버 → **Environment**에 `TESTER_USERS` 를 넣고 저장해요. **아이디나 이메일** 둘 다 돼요. 여러 개면 쉼표로 이어요(예: `내이메일@gmail.com,haru`). 대소문자는 구분하지 않아요.
   - **이메일**을 넣었다면: 게임에서 그 이메일의 **Google 계정으로 로그인**(또는 「👤 계정 → Google 계정 연결」)을 한 번 해 주세요. 그때 서버가 테스터로 기억해요(이메일 자체는 저장하지 않고 확인용 암호값만 남겨요).
   - **아이디**를 넣었다면: 그 아이디로 로그인하면 돼요(메뉴 위 👤 단추에 보이는 이름).
2. 서버가 다시 켜지면 게임을 새로 열어요. 그 계정은 **모든 현질템을 가진 것으로** 처리돼서, 상점에서 「장착하기」로 바로 써 볼 수 있어요. 현질 검을 장착하면 능력치와 궁극기도 진짜처럼 들어가요.
3. **무료 모드(`SHOP_MODE=free`)여도 테스터에게는 상점 탭이 보여요.** 다른 사람에게는 그대로 숨겨져요.
4. 시험이 끝나면 `TESTER_USERS` 값을 지우면 돼요.

## 지금 상태: 테스트 결제

- 키를 아무것도 안 넣으면 토스 개발자 문서에 **공개된 테스트 키**를 써요. 결제창도 진짜처럼 뜨지만 **실제로 돈이 나가지 않아요.** (결제창과 상점에 「테스트 결제」 표시가 나와요)
- 테스트로 산 상품은 **테스트 키일 때만** 보관함에 보여요. 나중에 진짜 키로 바꾸면 테스트로 산 것은 저절로 빠져요.

## 내 테스트 키로 바꾸기 (선택, 5분)

1. https://developers.tosspayments.com 에 가입 → 「API 키」 메뉴에서 **테스트 클라이언트 키(test_ck_…)**와 **테스트 시크릿 키(test_sk_…)**를 복사해요.
2. Render → 서버 → **Environment** → `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`에 각각 붙여 넣고 저장해요.
3. 개발자센터에서 테스트 결제 내역을 볼 수 있어요.

> ⚠️ 시크릿 키(`…_sk_…`)는 비밀번호와 같아요. **채팅·깃허브·게임 파일에 절대 붙이지 말고** Render 환경변수에만 넣으세요.

## 진짜로 돈 받기 (사업자등록 뒤)

1. **사업자등록**을 해요(개인사업자도 돼요. 업종 예: 전자상거래 · 게임 소프트웨어).
2. 토스페이먼츠에서 **전자결제 계약**(심사)을 해요. 심사 때 사이트에 **상호 · 대표자 · 사업자번호 · 주소 · 연락처 · 환불 규정**이 보여야 해요.
3. 심사가 끝나면 받는 **라이브 키(live_ck_… / live_sk_…)**를 Render의 `TOSS_CLIENT_KEY`, `TOSS_SECRET_KEY`에 넣어요.
4. `SHOP_CONTACT`에 환불·문의 연락처(이메일 등)를 넣어요. 결제창에 보여요.
5. **`DATABASE_URL`(Postgres)을 꼭 넣어요.** 무료 Render 서버는 다시 켜질 때 파일이 지워져서, Postgres 없이 팔면 **산 상품 기록이 사라질 수 있어요.**

## 알아 두면 좋은 것

- 가격은 서버(`app.py`의 `SHOP_PRODUCTS`)에 있는 값만 믿어요. 게임 쪽에서 금액을 바꿔도, 결제창 주소를 고쳐도 승인되지 않아요.
- 같은 주문은 한 번만 승인돼요. 이미 가진 상품은 다시 살 수 없어요.
- **환불(결제 취소)**은 아직 게임·서버에 단추가 없어요. 토스페이먼츠 상점 관리자 화면에서 취소하고, 상품을 회수하려면 DB의 `shop_orders`에서 그 주문의 `status`를 `refunded`로 바꾸면 보관함에서 빠져요.
- 결제창에 **「만 19세 미만은 보호자 동의 후 결제」 확인 칸**이 있어요. 체크해야 결제 단추가 눌려요. (보호자 동의 없는 미성년자 결제는 보호자가 취소를 요청할 수 있어요)
- 한국에서 유료 아이템을 파는 게임을 공개 배포하려면 원칙적으로 **게임물관리위원회 등급분류**가 필요해요. 진짜 판매 전에 확인하세요.
- 가상계좌(무통장 입금)는 입금 알림(웹훅)이 필요해서 지금은 뺐어요.
