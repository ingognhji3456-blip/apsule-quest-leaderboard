# 구글 플레이에 BEAT BLADE 올리는 방법

게임은 지금처럼 서버(Render)의 `/play`에서 돌아가요. 구글 플레이 앱은 그 화면을 **주소창 없이 전체 화면으로 띄우는 껍데기(TWA)**예요.
그래서 **게임을 고치면 서버만 새로 올려도 앱에 반영**돼요. 앱은 저장해 둔 게임을 먼저 띄우고 뒤에서 새 버전을 받기 때문에, 바뀐 내용은 *다음 실행*부터 보여요.

> 코드 쪽 준비는 끝나 있어요.
> - 앱 설정 파일(`/manifest.webmanifest`)
> - 오프라인 저장(`/sw.js`)
> - 아이콘(`/app/…`)
> - 앱 연결 확인(`/.well-known/assetlinks.json`)
> - 개인정보처리방침(`/privacy`)
> - 계정 삭제(`/delete-account`와 게임 안 「👤 계정 → 계정 삭제」)
>
> 앱 안에서는 **「구매하기」와 가격이 숨겨져요.** 앱에서 디지털 상품을 팔려면 구글 플레이 결제를 써야 하기 때문이에요. 웹에서 산 상품은 로그인하면 앱에서도 쓸 수 있어요.

## 0단계 · 준비물

| 준비물 | 내용 |
|---|---|
| 구글 플레이 개발자 계정 | **성인 명의**, 등록비 약 25달러(한 번만). 미성년자는 부모님 계정으로 만들어요 |
| 서버 | 이번 버전이 Render에 올라가 있어야 해요. `…onrender.com/manifest.webmanifest`가 열리면 돼요 |
| 테스터 12명 | 새 개인 계정은 **테스터 12명이 14일 동안 비공개 테스트**를 해야 정식 출시할 수 있어요. 친구나 가족의 구글 계정이면 돼요 |
| 스토어 이미지 | 저장소의 `game/app/` 폴더에 다 만들어 뒀어요(아래 표) |

| 파일 | 쓰는 곳 |
|---|---|
| `game/app/icon-512.png` | 앱 아이콘 (512×512) |
| `game/app/feature-1024x500.png` | 그래픽 이미지 (1024×500) |
| `game/app/store/1-menu.png` ~ `6-skins.png` | 휴대전화 스크린샷 (1920×1080, 가로) |

## 1단계 · 앱 파일 만들기 (PWABuilder, 10분)

1. https://www.pwabuilder.com 에 들어가 주소 칸에 `https://capsule-quest-leaderboard.onrender.com/play` 를 넣고 **Start**를 눌러요.
   무료 서버가 자고 있으면 첫 검사가 실패할 수 있어요. 1분 뒤 다시 해 보세요.
2. 점수표가 나오면 **Package For Stores** → **Android** → **Generate Package**를 눌러요.
3. 설정 화면에서 이렇게 넣어요.
   - **Package ID**: 예) `com.내이름.beatblade`. 영어 소문자와 점으로 써요. ⚠️ **나중에 못 바꿔요.**
   - **App name**: `BEAT BLADE · MACHINA`
   - **Launcher name**: `BEAT BLADE`
   - **Display mode**: `Fullscreen`
   - **Orientation**: `Landscape`
   - **Signing key**: `Create new`를 고르고 이름·단체는 아무거나 넣어요. 비밀번호는 PWABuilder가 만들어 줘요.
   - Display mode와 Orientation은 앱 설정 파일 값이 기본으로 들어와 있을 거예요.
4. **Download**를 누르면 zip 파일이 받아져요. 안에 이런 게 있어요.
   - `…aab`: 구글 플레이에 올릴 앱 파일
   - `signing.keystore`, `signing-key-info.txt`: **서명 열쇠와 비밀번호**
   - `assetlinks.json`: 앱 연결 확인 값

> ⚠️ **`signing.keystore`와 `signing-key-info.txt`는 USB나 클라우드 같은 곳 두 군데 이상에 따로 보관하세요.** 잃어버리면 앱을 업데이트할 수 없어요. **깃허브나 채팅에는 절대 올리지 마세요.**

---

## 2단계 · 앱 연결 확인 값 넣기 (주소창 없애기)

1. zip 안의 `assetlinks.json`을 메모장으로 열어요.
2. `"package_name"` 값과 `"sha256_cert_fingerprints"` 안의 값(`AB:CD:…`로 된 긴 글자)을 복사해요.
3. Render → 서버 → **Environment**에 넣어요.
   - `TWA_PACKAGE` = 패키지 이름 (예: `com.내이름.beatblade`)
   - `TWA_SHA256` = 지문 (`AB:CD:…`)
4. 저장해서 서버가 다시 켜지면 `https://…onrender.com/.well-known/assetlinks.json`을 열어 값이 보이는지 확인해요.

> 3단계에서 앱을 올린 뒤에 꼭 할 일이 하나 더 있어요. 플레이 콘솔 **설정 → 앱 무결성 → 앱 서명** 화면에서 **「앱 서명 키 인증서」의 SHA-256 지문**을 복사해 `TWA_SHA256`에 **쉼표로 이어서** 넣어요(예: `AB:CD:…,12:34:…`). 이걸 안 하면 플레이 스토어에서 받은 앱 위쪽에 주소창이 보여요.

## 3단계 · 플레이 콘솔에 앱 만들기

1. https://play.google.com/console 에서 개발자 계정을 만들고(본인 인증) **앱 만들기**를 눌러요.
   - 앱 이름 `BEAT BLADE · MACHINA`, 기본 언어 한국어, **게임**, **무료**
2. **스토어 등록정보**를 채워요.
   - 간단한 설명(80자): `박자에 맞춰 베는 리듬 액션! 70명의 보스, 7개의 챕터.`
   - 자세한 설명: 게임 소개, 챕터, 보스 러시, 스킨 등을 자유롭게 써요.
   - 아이콘, 그래픽 이미지, 스크린샷: 0단계 표의 파일을 올려요.
   - 카테고리: 게임 → 음악(또는 액션)
3. **앱 콘텐츠**(왼쪽 메뉴)의 설문을 하나씩 채워요.
   - **개인정보처리방침**: `https://capsule-quest-leaderboard.onrender.com/privacy`
   - **광고**: 없음
   - **앱 액세스**: 로그인 없이 모든 기능을 쓸 수 있음(로그인은 선택)
   - **콘텐츠 등급**: 설문을 작성하면 등급이 자동으로 나와요(한국 등급 포함). 판타지 전투가 있다고 답하면 돼요.
   - **타겟층**: 만 13세 이상을 권장해요. 13세 미만을 고르면 가족 정책 심사가 추가로 붙어요.
   - **데이터 보안**: 아래처럼 답하면 개인정보처리방침과 맞아요.
     - 수집하는 것: 사용자 ID(아이디), 앱 활동(게임 진행 기록), 구매 내역
     - 공유하지 않음, 전송 중 암호화됨(https), 사용자가 삭제를 요청할 수 있음
     - 계정 삭제 주소: `https://capsule-quest-leaderboard.onrender.com/delete-account`
4. **테스트 → 비공개 테스트**에서 트랙을 만들고, 1단계의 `.aab`를 올려요. 테스터 이메일을 12명 이상 넣고 검토를 제출해요.
5. 테스터들이 초대 링크로 참여해서 **14일 동안 설치해 두면**, 그다음 **프로덕션 출시**를 신청할 수 있어요.

## 알아 두면 좋은 것

- **무료로 출시하려면** Render 환경변수 `SHOP_MODE` = `free` 를 넣어 두세요. 웹·앱 모두에서 유료 상점 탭이 사라져요.

- **무료 서버(Render free)는 15분쯤 안 쓰면 잠들어요.** 앱은 저장해 둔 게임으로 바로 켜지지만, 로그인·저장·랭킹은 서버가 깰 때까지(최대 1분) 늦어요. 정식 출시 때는 Render 유료(월 약 7달러)와 Postgres(`DATABASE_URL`)를 추천해요.
- 앱 파일을 PWABuilder에서 다시 만들어 올리는 건 앱 이름이나 아이콘을 바꿀 때뿐이에요. 이때 **같은 서명 열쇠**를 쓰고, 버전 번호는 올려야 해요.
- 앱 안에서 유료 상품을 팔고 싶으면 나중에 **구글 플레이 결제**를 따로 연결해야 해요.
