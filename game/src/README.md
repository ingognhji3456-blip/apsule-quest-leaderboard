# BeatBlade 소스 (game/src)

게임은 이 폴더의 조각들을 이어 붙여 HTML 파일 하나로 만든다. 빌드: `python3 tools/game/bundle.py game/BeatBlade-XX.html`

| 파일 | 내용 |
|---|---|
| `head.html` | 문서 머리 (제목, 메타) |
| `style.css` | 기본 스타일 (일부 스타일은 js가 실행 중에 추가) |
| `body.html` | 화면 뼈대 (로비·전투 화면 요소) |
| `foot.html` | 문서 끝 |
